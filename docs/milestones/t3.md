# T3 — GitHub Issues

- Status: Accepted
- Date: 2026-07-26

## Delivered

- GitHub issue import, read, list, create, and update;
- comments, labels, assignees, milestones, close, and reopen;
- provider-neutral normalized ticket contract and stable typed failures;
- HMAC-SHA256 webhook validation and issue-payload normalization;
- durable webhook deduplication;
- polling reconciliation through the same provider projection path;
- durable idempotent outbound operations;
- run-status comments and labels with optional success closure;
- sync state and retry-ready failure persistence.

## Invariants

- GitHub owns issue content and open/closed state after binding;
- local planning status is preserved while a remote issue remains open;
- provider failures never alter Kouro run results;
- credentials are injected and never persisted;
- duplicate webhook deliveries and run events do not duplicate writes;
- GitHub Projects remain out of scope.
