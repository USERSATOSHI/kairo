# M5 Acceptance Record — Feature-development vertical slice

- Status: Complete
- Accepted: 2026-07-26
- Scope: Worktree-backed feature planning, implementation, bounded repair,
  read-only review, artifact-bound approvals, restart recovery, and delivery

M5 composes the M1–M4 boundaries into one executable feature-development
workflow. ADR-0009 adds deterministic run-duration and invocation limits plus
explicit failed completion nodes.

## Vertical boundary proven

```text
pinned repository → isolated worktree → plan → approval
                                      → implement → lint → format → test
                                           ↑              ↙ failure output
                                           └─ read-only review changes
                                      → artifact-bound delivery approval
                                      → controlled commit → named branch
```

The fixture publishes agent outputs and transcripts at attempt scope.
Validation results, Git status, and the binary diff are run-level checksum references.
Delivery approval includes every checksum published before the request.

## Compatibility and performance

- Run limits and terminal results are additive compiled-bundle fields.
- Start and observed timestamps are additive event fields; workflows without a
  duration limit retain their existing scheduling path.
- SQLite adds a run-artifact projection without changing append-only history
  semantics.
- Execution remains sequential and bounded to 30 node invocations. No
  concurrency, merge automation, or deployment behavior is introduced.
