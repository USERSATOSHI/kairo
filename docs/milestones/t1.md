# T1 — Local ticket foundation

- Status: Accepted
- Date: 2026-07-26

## Scope

T1 adds mutable planning tickets beside Kairo's existing deterministic runtime.
It does not connect tickets to runs or add external providers.

## Delivered

- `@kairo/tickets` domain model and typed errors
- ticket, binding, comment, and relationship validation
- repository port and local ticket application service
- optimistic ticket revisions
- SQLite ticket, comment, label, assignee, relationship, binding, and Kanban
  tables
- `@kairo/ticket-provider-local` lifecycle adapter
- pure planning-column derivation and explicit move rules

## Invariants

- local tickets require no Git repository, remote, network, or provider token;
- Kairo ticket IDs remain stable across edits and restarts;
- ticket status contains planning state only;
- execution state is not persisted as a Kanban column;
- invalid board movements fail instead of changing workflow state;
- local ticket history is cancelled, not silently deleted.
