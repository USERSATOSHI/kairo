# M1 Acceptance Record — Deterministic Compiler and Simulator

- Status: Complete
- Accepted: 2026-07-26
- Scope: Pure compilation, replay, scheduling, transition, approval, and
  recovery semantics

M1 performs no external workflow effects. SQLite persistence, command
execution, worktrees, Git operations, HTTP transport, and coding harnesses
remain outside this milestone.

- a TypeScript workflow definition;
- manifest metadata and permissions;
- a prompt;
- a TypeScript-exported JSON schema;
- a pinned shared subworkflow.

It compiles to:

```text
sha256:4134c2f6cb28d9528cbffe5a7da1e2ca6e5086a1d22e8dd7fd3f3d5e37c0399c
```

The exact canonical bytes are checked into
`tests/fixtures/golden/feature-simulation.bundle.json`.

## Boundary proven

```text
compiled bundle + ordered durable events
               ↓
          pure projection
               ↓
     deterministic ordered intents
```

Infrastructure in M2 may commit those intents, but cannot change their
selection semantics.
